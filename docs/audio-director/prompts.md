# LLM-промпты — централизованный реестр

Все промпты, используемые в Audio Director, хранятся как функции в `src/lib/audioPrompts.ts` (создаётся в PR 1). Этот документ описывает их назначение, входы/выходы и связанные модели.

## 1. `extractCharactersPrompt(book)` — экстракция персонажей

**PR:** 1
**Модель:** `gemini-3.1-pro-preview` (выбираема в Settings)
**Вход:** `ParsedFB2` — структура книги (title, author, chapters[]). Передаём первые ~30 000 символов, склеенных через границы глав.
**Выход:** JSON

```json
{
  "characters": [
    {
      "name": "Анна",
      "description": "Молодая исследовательница, главная героиня",
      "isMain": true,
      "suggestedGender": "female",
      "suggestedTone": "youthful"
    }
  ]
}
```

`suggestedGender` и `suggestedTone` используем для авто-подбора дефолтного голоса в `voicePresets.suggestVoice()`.

**Промпт (черновик):**

```
Ты — литературный аналитик, готовящий аудиокнигу. Прочитай книгу и верни СТРОГО JSON со списком значимых действующих лиц.

Книга: "{title}", автор: {author}.

Текст (может быть сокращён):
{textSnippet}

Верни JSON со схемой:
{
  "characters": [
    {
      "name": "...",
      "description": "1-2 предложения, кто это и какую роль играет",
      "isMain": true | false,
      "suggestedGender": "male" | "female" | "neutral",
      "suggestedTone": "youthful" | "mature" | "elderly" | "child" | "intimidating" | "warm" | "neutral"
    }
  ]
}

Правила:
- Не более 12 персонажей. Если больше — оставь самых важных.
- Не включай безымянных эпизодических персонажей.
- Только JSON, без markdown и комментариев.
```

## 2. `markupChapterPrompt(chapter, characters)` — разметка главы на блоки

**PR:** 2
**Модель:** `gemini-3.1-flash-lite-preview`
**Вход:** один объект `Chapter` (text), список известных имён персонажей.
**Выход:** JSON

```json
{
  "blocks": [
    { "speaker": "Рассказчик", "emotion": null, "text": "..." },
    { "speaker": "Анна", "emotion": "удивление", "text": "..." }
  ]
}
```

**Контракты:**
- `speaker` — либо строго одно из имён, переданных в `knownCharacters`, либо `"Рассказчик"`.
- Если ИИ встречает реплику от неизвестного персонажа — называет его `"Рассказчик"` (мы потом можем добавить персонажа вручную).
- Авторские комментарии вокруг прямой речи (например, «— спросила Анна») могут быть отдельным блоком `Рассказчик` или склеены с предыдущим — на усмотрение модели.

**Промпт (черновик):**

```
Ты — режиссёр аудиокниги. Размечай текст главы на блоки реплик для озвучки.

Известные персонажи: {namesCsv}. Все остальные блоки относи к "Рассказчик".

Текст главы:
{chapterText}

Верни СТРОГО JSON:
{
  "blocks": [
    { "speaker": "...", "emotion": "...", "text": "..." }
  ]
}

Правила:
- speaker — одно из: {namesCsv}, или "Рассказчик".
- emotion — короткий русский ярлык (1 слово) или null.
- text — точный фрагмент исходника, без сокращений и без кавычек/тире, обозначающих прямую речь.
- Сохрани порядок текста.
- Только JSON, без markdown.
```

## 3. `ttsBlockPrompt(block, casting)` — формирование TTS-инпута для одного блока

**PR:** 3
**Модель:** `gemini-3.1-flash-tts-preview`

Не отдельный LLM-вызов — это **функция склейки** входа для TTS. Берёт `ScriptBlock` и `BookCasting`, возвращает `{contents, speechConfig}`.

Для блока:
- single-speaker: voice = casting голоса спикера, style-промпт = casting.styleHint + (опционально) emotion → audio tag в начале текста.
- Если в `casting.styleHint` уже есть инструкция — клеим как префикс (см. формат в `voices.md` → «Стиль через system-промпт»).

Пример сборки:

```ts
const tagged = block.emotion ? `[${block.emotion}] ${block.text}` : block.text;
const contents = casting.styleHint
  ? `${casting.styleHint}\n${tagged}`
  : tagged;
```

## 4. (опционально, PR 3) `mergeChapterDialoguePrompt` — пакетная multi-speaker генерация

Если 2 соседних блока с разными спикерами идут подряд и оба укладываются в лимит 8192 токена, можно отправить multi-speaker запрос с обоими голосами за один вызов. Экономит время. Реализация — bonus после базового кейса.

## Тестирование промптов

Все промпты валидируются на тестовом сэмпле — фрагмент из `Войны и мира` (RU, диалог Анны Павловны и князя Василия). Тестовый скрипт — `scripts/test-prompts.mjs` (создаётся в PR 1).
